Conditional Statements in Python

Conditional statements are used to make decisions in a program. They execute different blocks of code depending on whether a condition is True or False.

Why Do We Need Conditional Statements?

  • Decision Making
  • User Authentication
  • Validation
  • Grading Systems
  • Loan Approval Systems
  • Game Logic

1. if Statement

The if statement executes code only when the condition is True.

age = 20 if age >= 18: print("Eligible to Vote")

Output

Eligible to Vote

Syntax of if Statement

if condition: statement

2. if else Statement

Used when there are two possible outcomes.

age = 15 if age >= 18: print("Eligible") else: print("Not Eligible")
Not Eligible

Syntax of if else

if condition: statement else: statement

3. elif Statement

elif stands for "else if". It is used when multiple conditions need to be checked.

marks = 82 if marks >= 90: print("A+") elif marks >= 75: print("A") elif marks >= 60: print("B") else: print("C")
A

Syntax of elif

if condition: statement elif condition: statement else: statement

4. Nested if Statement

An if statement inside another if statement is called a nested if.

age = 20 license = True if age >= 18: if license: print("Can Drive")
Can Drive

Interview Questions

1. What is the difference between if and elif?

if starts checking conditions. elif checks additional conditions if previous ones fail.

2. What is a nested if statement?

An if statement inside another if statement.

3. Which operator checks equality?

==

4. Can we have multiple elif blocks?

Yes, we can use multiple elif blocks.

5. Is else mandatory?

No, else is optional.
