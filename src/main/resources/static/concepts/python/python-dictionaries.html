Dictionaries in Python

A Dictionary is a collection of key-value pairs. Each key is unique and is used to access its corresponding value.

Why Use Dictionaries?

  • Fast Data Retrieval
  • Store Related Information
  • Real-world Data Representation
  • Efficient Searching

Creating a Dictionary

student = { "name":"Deepu", "age":21, "course":"Python" } print(student)
{'name':'Deepu','age':21,'course':'Python'}

Dictionary Characteristics

  • Stores Data as Key-Value Pairs
  • Mutable
  • Keys Must Be Unique
  • Values Can Be Duplicates
  • Ordered (Python 3.7+)

Accessing Values

student = { "name":"Deepu", "age":21 } print(student["name"])
Deepu

Using get()

student = { "name":"Deepu", "age":21 } print(student.get("age"))
21

Adding New Elements

student = { "name":"Deepu" } student["age"] = 21 print(student)
{'name':'Deepu','age':21}

Updating Existing Values

student = { "name":"Deepu", "age":21 } student["age"] = 22 print(student)
{'name':'Deepu','age':22}

Removing Elements

pop()

student = { "name":"Deepu", "age":21 } student.pop("age") print(student)
{'name':'Deepu'}

del

student = { "name":"Deepu", "age":21 } del student["age"] print(student)
{'name':'Deepu'}

Dictionary Methods

Method Description
get() Returns Value
keys() Returns Keys
values() Returns Values
items() Returns Key-Value Pairs
pop() Removes Key
update() Updates Dictionary
clear() Removes All Items

keys() Method

student = { "name":"Deepu", "age":21 } print(student.keys())
dict_keys(['name','age'])

values() Method

student = { "name":"Deepu", "age":21 } print(student.values())
dict_values(['Deepu',21])

items() Method

student = { "name":"Deepu", "age":21 } print(student.items())
dict_items([('name','Deepu'),('age',21)])

Looping Through Dictionary

student = { "name":"Deepu", "age":21 } for key,value in student.items(): print(key,value)
name Deepu age 21

Nested Dictionary

students = { 1:{ "name":"Deepu", "age":21 }, 2:{ "name":"Rahul", "age":22 } } print(students[1]["name"])
Deepu

Dictionary Comprehension

squares = { x:x*x for x in range(5) } print(squares)
{0:0,1:1,2:4,3:9,4:16}

Program: Student Information

student = { "name":"Deepu", "age":21, "course":"Python" } for k,v in student.items(): print(k,":",v)
name : Deepu age : 21 course : Python

Program: Word Frequency Counter

text = "python python java" words = text.split() freq = {} for word in words: freq[word] = freq.get(word,0)+1 print(freq)
{'python':2,'java':1}
