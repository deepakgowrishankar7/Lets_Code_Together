Tuples in Python

A Tuple is an ordered collection of elements. Unlike Lists, Tuples are immutable, meaning their values cannot be changed after creation.

Why Use Tuples?

  • Faster than Lists
  • Data Protection
  • Used for Fixed Data
  • Consumes Less Memory

Creating a Tuple

numbers = (10,20,30,40) print(numbers)
(10, 20, 30, 40)

Tuple Characteristics

  • Ordered
  • Immutable
  • Allows Duplicates
  • Can Store Different Data Types

Accessing Tuple Elements

numbers = (10,20,30,40) print(numbers[0]) print(numbers[2])
10 30

Negative Indexing

numbers = (10,20,30,40) print(numbers[-1])
40

Tuple Slicing

numbers = (10,20,30,40,50) print(numbers[1:4])
(20, 30, 40)

Tuple Length

numbers = (10,20,30,40) print(len(numbers))
4

Tuple Methods

Method Description
count() Counts occurrences
index() Returns position

count() Method

numbers = (10,20,10,30) print(numbers.count(10))
2

index() Method

numbers = (10,20,30) print(numbers.index(20))
1

Tuple Packing

Storing multiple values into a tuple.

student = ("Deepu",21,"India") print(student)
('Deepu', 21, 'India')

Tuple Unpacking

Extracting tuple values into variables.

student = ("Deepu",21,"India") name,age,country = student print(name) print(age) print(country)
Deepu 21 India

Looping Through Tuple

numbers = (10,20,30) for num in numbers: print(num)
10 20 30

Nested Tuple

students = ( ("Deepu",21), ("Rahul",22) ) print(students[0])
('Deepu', 21)

Tuple vs List

Tuple List
Immutable Mutable
() []
Faster Slower
Less Memory More Memory

Can We Modify a Tuple?

numbers = (10,20,30) numbers[0] = 100
TypeError

Tuples cannot be modified after creation.

Convert Tuple to List

numbers = (10,20,30) temp = list(numbers) temp[0] = 100 numbers = tuple(temp) print(numbers)
(100, 20, 30)

Program: Sum of Tuple Elements

numbers = (10,20,30) print(sum(numbers))
60

Program: Largest Element

numbers = (10,40,80,20) print(max(numbers))
80

Program: Smallest Element

numbers = (10,40,80,20) print(min(numbers))
10
