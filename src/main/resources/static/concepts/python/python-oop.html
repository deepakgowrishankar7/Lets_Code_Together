Object Oriented Programming (OOP) in Python

Object Oriented Programming (OOP) is a programming paradigm that organizes code using classes and objects. It helps build reusable, secure, and scalable applications.

Why OOP?

  • Code Reusability
  • Modularity
  • Security
  • Easy Maintenance
  • Real World Modeling

Class and Object

A Class is a blueprint. An Object is an instance of a class.

class Student: pass s1 = Student() print(type(s1))
<class '__main__.Student'>

Creating a Class

class Student: name = "Deepu" obj = Student() print(obj.name)
Deepu

Constructor (__init__)

A constructor initializes object data automatically.

class Student: def __init__(self,name,age): self.name = name self.age = age s1 = Student("Deepu",21) print(s1.name) print(s1.age)
Deepu 21

Instance Variables

class Employee: def __init__(self,name,salary): self.name = name self.salary = salary e1 = Employee("Rahul",50000) print(e1.name)
Rahul

Methods

class Student: def greet(self): print("Welcome Student") s1 = Student() s1.greet()
Welcome Student

The self Keyword

self refers to the current object. It is used to access instance variables and methods.

Encapsulation

Encapsulation means binding data and methods together. Private variables are used to hide data.

class Bank: def __init__(self): self.__balance = 5000 def showBalance(self): print(self.__balance) b = Bank() b.showBalance()
5000

Inheritance

Inheritance allows one class to acquire properties of another class.

class Animal: def sound(self): print("Animal Sound") class Dog(Animal): pass d = Dog() d.sound()
Animal Sound

Types of Inheritance

Type Description
Single One Parent One Child
Multiple Multiple Parents
Multilevel Chain of Classes
Hierarchical One Parent Multiple Children

Method Overriding

class Animal: def sound(self): print("Animal Sound") class Dog(Animal): def sound(self): print("Bark") d = Dog() d.sound()
Bark

super() Method

class Parent: def show(self): print("Parent Method") class Child(Parent): def show(self): super().show() print("Child Method") c = Child() c.show()
Parent Method Child Method

Polymorphism

Polymorphism means one interface, many forms.

class Cat: def sound(self): print("Meow") class Dog: def sound(self): print("Bark") animals = [Cat(),Dog()] for a in animals: a.sound()
Meow Bark

Abstraction

Abstraction hides implementation details and shows only essential features.

from abc import ABC,abstractmethod class Vehicle(ABC): @abstractmethod def start(self): pass class Car(Vehicle): def start(self): print("Car Started") c = Car() c.start()
Car Started

Real World Example

class Student: def __init__(self,name,marks): self.name = name self.marks = marks def display(self): print(self.name,self.marks) s1 = Student("Deepu",95) s1.display()
Deepu 95
