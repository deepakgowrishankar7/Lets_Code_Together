Python Operators

Operators are special symbols used to perform operations on variables and values.

Types of Operators

  • Arithmetic Operators
  • Assignment Operators
  • Comparison Operators
  • Logical Operators
  • Bitwise Operators
  • Membership Operators
  • Identity Operators

1. Arithmetic Operators

Operator Description
+ Addition
- Subtraction
* Multiplication
/ Division
% Modulus
** Power
// Floor Division
a = 10 b = 3 print(a+b) print(a-b) print(a*b) print(a/b) print(a%b) print(a**b) print(a//b)
13 7 30 3.333333 1 1000 3

2. Assignment Operators

Operator Example
= x = 10
+= x += 5
-= x -= 5
*= x *= 5
/= x /= 5
x = 10 x += 5 print(x)
15

3. Comparison Operators

Operator Description
== Equal To
!= Not Equal To
> Greater Than
< Less Than
>= Greater Than Equal
<= Less Than Equal
a = 10 b = 20 print(a == b) print(a != b) print(a < b) print(a > b)
False True True False

4. Logical Operators

Operator Description
and Returns True if both conditions are True
or Returns True if any condition is True
not Reverses result
x = True y = False print(x and y) print(x or y) print(not x)
False True False

5. Bitwise Operators

Operator Description
& AND
| OR
^ XOR
~ NOT
<< Left Shift
>> Right Shift
a = 5 b = 3 print(a & b) print(a | b)
1 7

6. Membership Operators

Used to check whether a value exists in a sequence.

Operator Description
in Value exists
not in Value does not exist
numbers = [10,20,30] print(20 in numbers) print(50 in numbers)
True False

7. Identity Operators

Used to compare memory locations.

Operator Description
is Same object
is not Different object
x = [1,2] y = x print(x is y)
True

Real World Example

age = 20 if age >= 18: print("Eligible to Vote")
Eligible to Vote

Interview Questions

1. Difference between == and is ?

== compares values. is compares memory location.

2. What is Floor Division?

Returns integer result after division.

3. What is Modulus Operator?

Returns remainder.

4. Which operator is used for power?

** operator.

Common Mistakes

  • Using = instead of ==
  • Confusing is with ==
  • Wrong logical conditions
  • Division by zero

Summary

Operators perform operations on data. Python supports Arithmetic, Assignment, Comparison, Logical, Bitwise, Membership and Identity operators. Understanding operators is important because they are used in almost every Python program.
