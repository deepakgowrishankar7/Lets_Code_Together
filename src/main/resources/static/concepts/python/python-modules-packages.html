Modules and Packages in Python

Modules and Packages help organize code into reusable and manageable components.

What is a Module?

A module is a Python file containing functions, classes, and variables.

import math print(math.sqrt(25))
5.0

Advantages of Modules

  • Code Reusability
  • Better Organization
  • Easier Maintenance
  • Modular Programming

Import Statement

import math print(math.factorial(5))
120

Import Specific Functions

from math import sqrt print(sqrt(64))
8.0

Import Multiple Functions

from math import sqrt,factorial,pow

Alias Names

import math as m print(m.sqrt(36))
6.0

Math Module

import math print(math.sqrt(81)) print(math.factorial(5)) print(math.pi)

Random Module

import random print(random.randint(1,10)) print(random.choice(["Red","Blue","Green"]))

Datetime Module

from datetime import datetime print(datetime.now())

OS Module

import os print(os.getcwd())

Sys Module

import sys print(sys.version)

Creating Custom Modules

# calculator.py def add(a,b): return a+b # main.py import calculator print(calculator.add(10,20))

What is a Package?

A package is a collection of related modules organized in folders.

project/ | |-- calculator/ | |-- __init__.py | |-- addition.py | |-- subtraction.py

__init__.py

Used to identify a folder as a Python package.

Importing from Packages

from calculator.addition import add print(add(10,20))
