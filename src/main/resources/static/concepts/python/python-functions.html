Functions in Python

Functions are reusable blocks of code used to perform specific tasks. They help reduce code duplication and improve readability.

Why Functions?

  • Code Reusability
  • Reduce Duplication
  • Easy Maintenance
  • Improves Readability
  • Modular Programming

Function Syntax

def function_name(): statement

Simple Function

def greet(): print("Welcome to Python") greet()
Welcome to Python

Function with Parameters

def greet(name): print("Hello", name) greet("Deepu")
Hello Deepu

Function with Multiple Parameters

def add(a,b): print(a+b) add(10,20)
30

Return Statement

The return statement sends a value back to the caller.

def add(a,b): return a+b result = add(10,20) print(result)
30

Difference Between print() and return

print() return
Displays output Sends value back
Cannot reuse result Can reuse result

Default Arguments

def greet(name="Guest"): print("Hello",name) greet() greet("Deepu")
Hello Guest Hello Deepu

Keyword Arguments

def student(name,age): print(name) print(age) student(age=21,name="Deepu")
Deepu 21

Variable Length Arguments (*args)

def total(*numbers): print(sum(numbers)) total(10,20) total(10,20,30,40)
30 100

Keyword Variable Arguments (**kwargs)

def student(**details): print(details) student(name="Deepu",age=21)
{'name':'Deepu','age':21}

Lambda Function

Lambda is an anonymous function.

square = lambda x : x*x print(square(5))
25

Recursion

A function calling itself is called recursion.

def display(n): if n==0: return print(n) display(n-1) display(5)
5 4 3 2 1

Factorial Using Recursion

def factorial(n): if n==1: return 1 return n * factorial(n-1) print(factorial(5))
120

Program: Even or Odd Using Function

def check(num): if num%2==0: return "Even" return "Odd" print(check(10))
Even

Program: Largest Number

def largest(a,b): if a>b: return a return b print(largest(10,20))
20

Program: Area of Circle

def area(radius): return 3.14 * radius * radius print(area(5))
78.5

Scope of Variables

Local Variable

def test(): x = 10 print(x) test()
10

Global Variable

x = 100 def test(): print(x) test()
100

Interview Questions

1. What is a function?

A reusable block of code that performs a specific task.

2. What is recursion?

A function calling itself.

3. Difference between parameter and argument?

Parameter → Variable in function definition. Argument → Value passed during function call.

4. What is lambda function?

A small anonymous function.

5. What are *args and **kwargs?

Used to accept variable number of arguments.
