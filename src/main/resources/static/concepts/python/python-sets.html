Sets in Python

A Set is an unordered collection of unique elements. Sets automatically remove duplicate values.

Why Use Sets?

  • Store Unique Values
  • Fast Searching
  • Mathematical Operations
  • Remove Duplicates Easily

Creating a Set

numbers = {10,20,30,40} print(numbers)
{10, 20, 30, 40}

Set Characteristics

  • Unordered
  • Unique Elements Only
  • Mutable
  • No Indexing

Duplicate Values

numbers = {10,20,20,30,30,40} print(numbers)
{10,20,30,40}

Duplicates are automatically removed.

Adding Elements

add()

numbers = {10,20,30} numbers.add(40) print(numbers)
{10,20,30,40}

update()

numbers = {10,20} numbers.update([30,40,50]) print(numbers)
{10,20,30,40,50}

Removing Elements

remove()

numbers = {10,20,30} numbers.remove(20) print(numbers)
{10,30}

Throws an error if element does not exist.

discard()

numbers = {10,20,30} numbers.discard(50) print(numbers)
{10,20,30}

No error if element is missing.

pop()

numbers = {10,20,30} numbers.pop() print(numbers)
Random element removed

clear()

numbers = {10,20,30} numbers.clear() print(numbers)
set()

Looping Through a Set

numbers = {10,20,30} for num in numbers: print(num)
10 20 30

Membership Test

numbers = {10,20,30} print(20 in numbers)
True

Union Operation

Combines all unique elements.

A = {1,2,3} B = {3,4,5} print(A.union(B))
{1,2,3,4,5}

Intersection Operation

Returns common elements.

A = {1,2,3} B = {2,3,4} print(A.intersection(B))
{2,3}

Difference Operation

A = {1,2,3} B = {2,3,4} print(A.difference(B))
{1}

Symmetric Difference

A = {1,2,3} B = {2,3,4} print(A.symmetric_difference(B))
{1,4}

Subset

A = {1,2} B = {1,2,3,4} print(A.issubset(B))
True

Superset

A = {1,2,3,4} B = {1,2} print(A.issuperset(B))
True

Convert List to Set

numbers = [10,20,20,30,30] result = set(numbers) print(result)
{10,20,30}

Program: Remove Duplicates

numbers = [1,2,2,3,3,4] unique = list(set(numbers)) print(unique)
[1,2,3,4]

Interview Questions

1. What is a Set?

An unordered collection of unique elements.

2. Does Set allow duplicates?

No.

3. Can we access elements using index?

No.

4. Difference between remove() and discard()?

remove() throws error if value doesn't exist. discard() does not.

5. What is Union?

Combines unique elements from both sets.

Common Mistakes

  • Trying to access by index
  • Expecting order in sets
  • Using remove() for missing elements
  • Forgetting duplicates are removed
