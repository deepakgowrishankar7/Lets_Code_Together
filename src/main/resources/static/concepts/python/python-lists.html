Lists in Python

A List is a collection of items stored in a single variable. Lists are ordered, changeable, and allow duplicate values.

Creating a List

numbers = [10,20,30,40] print(numbers)
[10, 20, 30, 40]

Characteristics of Lists

  • Ordered
  • Mutable (Can Change)
  • Allows Duplicates
  • Can Store Different Data Types

Accessing List Elements

numbers = [10,20,30,40] print(numbers[0]) print(numbers[2])
10 30

Negative Indexing

numbers = [10,20,30,40] print(numbers[-1])
40

List Slicing

numbers = [10,20,30,40,50] print(numbers[1:4])
[20, 30, 40]

Updating Elements

numbers = [10,20,30] numbers[1] = 100 print(numbers)
[10, 100, 30]

Adding Elements

append()

numbers = [10,20] numbers.append(30) print(numbers)
[10, 20, 30]

insert()

numbers = [10,20] numbers.insert(1,15) print(numbers)
[10, 15, 20]

Removing Elements

remove()

numbers = [10,20,30] numbers.remove(20) print(numbers)
[10, 30]

pop()

numbers = [10,20,30] numbers.pop() print(numbers)
[10, 20]

List Methods

Method Description
append() Add Item
insert() Insert Item
remove() Remove Item
pop() Remove by Index
sort() Sort List
reverse() Reverse List
count() Count Occurrences
index() Find Position

Sorting a List

numbers = [50,10,40,20] numbers.sort() print(numbers)
[10, 20, 40, 50]

Reversing a List

numbers = [1,2,3,4] numbers.reverse() print(numbers)
[4, 3, 2, 1]

Looping Through a List

numbers = [10,20,30] for num in numbers: print(num)
10 20 30

Nested Lists

students = [ ["Deepu",21], ["Rahul",22] ] print(students[0])
['Deepu', 21]

List Comprehension

A shorter way to create lists.

numbers = [x*x for x in range(5)] print(numbers)
[0, 1, 4, 9, 16]

Program: Sum of List Elements

numbers = [10,20,30] print(sum(numbers))
60

Program: Largest Element

numbers = [10,50,20,90] print(max(numbers))
90

Program: Smallest Element

numbers = [10,50,20,90] print(min(numbers))
10

Program: Count Occurrences

numbers = [10,20,10,30,10] print(numbers.count(10))
3

Interview Questions

1. What is a List?

An ordered mutable collection.

2. Can Lists store different data types?

Yes.

3. Difference between append() and insert()?

append() adds at end. insert() adds at specific position.

4. What is List Comprehension?

A concise way to create lists.

5. Are Lists mutable?

Yes.

Common Mistakes

  • Wrong Slicing
  • Using remove() on missing value
