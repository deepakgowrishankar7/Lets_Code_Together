Python Decorators & Functional Programming

A Decorator is a structural pattern in Python that allows you to dynamically wrap or modify the behavior of a function or class without permanently modifying its source code.

1. First-Class Functions & Closures

In Python, functions are first-class objects: they can be passed as arguments, returned from functions, and assigned to variables.

def outer_function(msg):
    # Inner closure function remembers 'msg' even after outer_function finishes
    def inner_function():
        print("Logged Message:", msg)
    return inner_function

my_log = outer_function("System Initialized")
my_log() # Output: Logged Message: System Initialized

2. Writing Custom Function Decorators

import time
from functools import wraps

def execution_timer(func):
    @wraps(func) # Preserves original function's name and docstring
    def wrapper(*args, **kwargs):
        start_time = time.time()
        result = func(*args, **kwargs)
        end_time = time.time()
        print(f"⏱️ Function '{func.__name__}' took {(end_time - start_time):.4f}s to run.")
        return result
    return wrapper

@execution_timer
def calculate_sum(n):
    return sum(range(n))

# Invoking decorated function
total = calculate_sum(1000000)
print("Total Sum:", total)

3. Decorators with Arguments

To accept parameters inside a decorator, add an extra outer wrapper layer:

def repeat(num_times):
    def decorator_repeat(func):
        @wraps(func)
        def wrapper(*args, **kwargs):
            for _ in range(num_times):
                result = func(*args, **kwargs)
            return result
        return wrapper
    return decorator_repeat

@repeat(num_times=3)
def greet(name):
    print(f"Hello, {name}!")

greet("Alice") # Prints 'Hello, Alice!' 3 times

4. Functional Tools (`map`, `filter`, `reduce`)

from functools import reduce

numbers = [1, 2, 3, 4, 5, 6]

# Map: Transform elements
squared = list(map(lambda x: x**2, numbers))

# Filter: Retain elements matching condition
evens = list(filter(lambda x: x % 2 == 0, numbers))

# Reduce: Cumulative aggregation
product = reduce(lambda x, y: x * y, numbers)

print("Squared:", squared) # [1, 4, 9, 16, 25, 36]
print("Evens:", evens)     # [2, 4, 6]
print("Product:", product) # 720
