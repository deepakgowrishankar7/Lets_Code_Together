Introduction to Python

What is Python?

Python is a high-level, interpreted, object-oriented programming language created by Guido van Rossum and released in 1991.

Python is famous for its simple syntax and readability. It is one of the most popular programming languages in the world.

Why Learn Python?

  • Easy to Learn
  • Simple Syntax
  • Huge Community Support
  • Used in AI and Machine Learning
  • Used in Data Science
  • Used in Web Development
  • Used in Automation
  • High Demand in Industry

Installing Python (Detailed)

Follow the steps for your operating system. We include verification and basic setup for development.

Windows

  1. Download the latest installer from python.org/downloads.
  2. Run the installer and check "Add Python to PATH" before clicking Install.
  3. Open PowerShell and verify: python --version and pip --version.

macOS

  1. Install via Homebrew (recommended): /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)" then brew install python.
  2. Or download the installer from python.org.
  3. Verify: python3 --version and pip3 --version.

Linux (Ubuntu/Debian)

sudo apt update
sudo apt install python3 python3-pip
python3 --version
pip3 --version

Creating a Virtual Environment

Use virtual environments to isolate project dependencies.

python -m venv venv
# activate on Windows PowerShell
venv\Scripts\Activate.ps1
# activate on macOS/Linux
source venv/bin/activate

pip install --upgrade pip

Installing Packages with pip

pip install requests
pip install flask
pip freeze  # list installed packages

Verify Installation

python --version

print("Hello World")

Quick Concepts (Rough)

  • Variables — store values: x = 5
  • Data Types — numbers, strings, lists, dicts
  • Control Flow — if, for, while
  • Functions — reusable code blocks: def fn():
  • Modules — import libraries using import
  • Files — read/write using open()

Practice
