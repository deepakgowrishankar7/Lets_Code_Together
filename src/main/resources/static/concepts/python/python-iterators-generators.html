Python Iterators, Generators & Context Managers

Generators provide memory-efficient lazy evaluation for large data sequences using the yield keyword. Context Managers handle automatic setup and cleanup of external resources.

1. Iterators vs Iterables

An Iterable is an object that returns an Iterator via `__iter__()`. An Iterator yields values one by one using `__next__()`.

numbers = [10, 20, 30]
iterator = iter(numbers)

print(next(iterator)) # 10
print(next(iterator)) # 20
print(next(iterator)) # 30
# next(iterator) -> Raises StopIteration exception!

2. Generators & `yield` Keyword

Generators compute items on-the-fly, allowing you to process datasets that are too large to fit in RAM. 

def fibonacci_generator(limit):
    a, b = 0, 1
    count = 0
    while count < limit:
        yield a # Pause function & emit value
        a, b = b, a + b
        count += 1

# Consuming generator
for num in fibonacci_generator(7):
    print(num, end=" ") # 0 1 1 2 3 5 8

3. Custom Context Managers (`__enter__` & `__exit__`)

Context Managers handle resource allocation and cleanup automatically using the with statement (e.g. closing files, releasing thread locks, database connections). 

class DatabaseConnectionManager:
    def __init__(self, db_name):
        self.db_name = db_name

    def __enter__(self):
        print(f"🔌 Connecting to database '{self.db_name}'...")
        return "ActiveConnection"

    def __exit__(self, exc_type, exc_val, exc_tb):
        print(f"🔒 Safely closing database connection to '{self.db_name}'.")
        return True # Suppress exceptions if needed

# Usage with context manager
with DatabaseConnectionManager("prod_db") as conn:
    print("Executing database query using:", conn)

4. `@contextmanager` Decorator

Using contextlib.contextmanager to write context managers with generator syntax:

from contextlib import contextmanager

@contextmanager
def temporary_file_logger(file_name):
    print(f"Opening log file {file_name}")
    file = open(file_name, "w")
    try:
        yield file
    finally:
        print(f"Closing log file {file_name}")
        file.close()

with temporary_file_logger("app.log") as f:
    f.write("Log entry recorded.\n")
