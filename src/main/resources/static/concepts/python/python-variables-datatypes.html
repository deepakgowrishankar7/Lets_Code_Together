Variables and Data Types in Python

What is a Variable?

A variable is a container used to store data.

name = "Deepu" age = 21

Variable Naming Rules

  • Must start with a letter or underscore
  • Cannot start with numbers
  • Cannot contain special characters
  • Case sensitive

Valid Variables

name student_name _age salary2025

Invalid Variables

2name @salary student-name

Python Data Types

Type Description
int Integer values
float Decimal values
str Text values
bool True or False
list Collection of items
tuple Immutable collection
set Unique values
dict Key value pairs

Integer Example

age = 21 print(age)
21

Float Example

salary = 25000.75 print(salary)
25000.75

String Example

name = "Deepu" print(name)
Deepu

Boolean Example

isStudent = True print(isStudent)
True

Checking Data Type

age = 21 print(type(age))

Dynamic Typing

Python automatically determines the type of variable.

x = 10 x = "Hello" print(x)
Hello

Multiple Variable Assignment

a,b,c = 10,20,30 print(a) print(b) print(c)
10 20 30

User Input Example

name = input("Enter Name : ") print(name)

Type Conversion

age = "21" age = int(age) print(age)
21

Interview Questions

1. What is a variable?

A container used to store data.

2. Is Python statically typed?

No, Python is dynamically typed.

3. What is type() function?

Used to determine the data type.

4. Difference between int and float?

int float
Whole Number Decimal Number
10 10.5

Common Mistakes

  • Using invalid variable names
  • Forgetting type conversion
  • Using reserved keywords as variables
  • Case sensitivity errors

Summary

Variables store data in Python. Python supports int, float, string, boolean, list, tuple, set and dictionary data types. Python is dynamically typed and easy to use.
