File Handling in Python

File Handling allows programs to store and retrieve data from files. Instead of keeping data only in memory, files provide permanent storage.

Why File Handling?

  • Store Data Permanently
  • Read Existing Data
  • Generate Reports
  • Save User Information
  • Work With Large Data

Opening a File

file = open("sample.txt","r")

Syntax:

open(filename, mode)

File Modes

Mode Description
r Read File
w Write File
a Append File
x Create New File
r+ Read and Write
a+ Append and Read

Reading a File

file = open("sample.txt","r") print(file.read()) file.close()

Read One Line

file = open("sample.txt","r") print(file.readline()) file.close()

Read All Lines

file = open("sample.txt","r") print(file.readlines()) file.close()

Writing to a File

file = open("sample.txt","w") file.write("Welcome to Python") file.close()

If file exists, old content will be replaced.

Appending Data

file = open("sample.txt","a") file.write("\nLearning File Handling") file.close()

New data is added at the end.

Creating a New File

file = open("newfile.txt","x") file.close()

Closing a File

file = open("sample.txt","r") file.close()

Always close files to free system resources.

Using with Statement

The with statement automatically closes files.

with open("sample.txt","r") as file: print(file.read())

Checking File Existence

import os if os.path.exists("sample.txt"): print("File Exists") else: print("File Not Found")
File Exists

Deleting a File

import os os.remove("sample.txt")

Program: Count Characters

with open("sample.txt","r") as file: data = file.read() print(len(data))

Program: Count Words

with open("sample.txt","r") as file: data = file.read() words = data.split() print(len(words))

Program: Count Lines

with open("sample.txt","r") as file: lines = file.readlines() print(len(lines))

Working with CSV Files

CSV stands for Comma Separated Values. Used to store tabular data.

import csv with open("students.csv","r") as file: reader = csv.reader(file) for row in reader: print(row)

Writing CSV Data

import csv with open("students.csv","w",newline="") as file: writer = csv.writer(file) writer.writerow(["Name","Age"]) writer.writerow(["Deepu",21])

Interview Questions

1. What is File Handling?

Reading and writing data from files.

2. Difference between w and a mode?

w replaces content. a adds content at the end.

3. Why use with statement?

Automatically closes files.

4. What is CSV?

Comma Separated Values file.

5. What happens if file doesn't exist in read mode?

FileNotFoundError occurs.

Common Mistakes

  • Wrong file path
  • Using wrong mode
  • Not handling exceptions
