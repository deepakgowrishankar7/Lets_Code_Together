SQL Subqueries

A subquery is a query inside another query. It lets you reuse query results in filters, calculations, or table sources.

Subquery in WHERE

Use a subquery to filter results based on values from another table.

SELECT name
FROM employees
WHERE department_id = (
  SELECT id
  FROM departments
  WHERE name = 'Sales'
);

Subquery in FROM

Use a subquery as a temporary table.

SELECT dept, avg_salary
FROM (
  SELECT department_id AS dept,
         AVG(salary) AS avg_salary
  FROM employees
  GROUP BY department_id
) AS dept_avg;

Correlated Subquery

Correlated subqueries reference the outer query and run once per row.

SELECT e.name
FROM employees e
WHERE e.salary > (
  SELECT AVG(salary)
  FROM employees
  WHERE department_id = e.department_id
);

IN, EXISTS, and ANY

Choose the right form based on your needs.

SELECT name
FROM employees
WHERE department_id IN (
  SELECT id
  FROM departments
  WHERE location = 'NYC'
);

SELECT name
FROM employees e
WHERE EXISTS (
  SELECT 1
  FROM orders o
  WHERE o.employee_id = e.id
);

When to Use Subqueries

Use subqueries for complex filters, derived tables, and when you need to compare rows against another query result.
