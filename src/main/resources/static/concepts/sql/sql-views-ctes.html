SQL Views, Materialized Views & CTEs

Views and Common Table Expressions (CTEs) allow developers to simplify complex queries, enforce security abstractions, and build recursive processing logic.

1. Standard SQL Views

A View is a virtual table based on the result-set of an SQL statement. It contains no physical data of its own. 

-- Create a View for High-Value Customers
CREATE VIEW v_high_value_customers AS
SELECT c.id, c.name, c.email, SUM(o.amount) as total_spent
FROM customers c
JOIN orders o ON c.id = o.customer_id
GROUP BY c.id, c.name, c.email
HAVING SUM(o.amount) >= 5000;

-- Querying the View like a regular table
SELECT * FROM v_high_value_customers WHERE email LIKE '%@gmail.com';

2. Materialized Views

Unlike standard views, a Materialized View physically stores the query result on disk for high performance on massive datasets. 

-- Create Materialized View (PostgreSQL / Oracle)
CREATE MATERIALIZED VIEW mv_daily_sales_summary AS
SELECT 
    DATE(order_date) as sales_date,
    COUNT(id) as total_orders,
    SUM(amount) as revenue
FROM orders
GROUP BY DATE(order_date);

-- Refresh Materialized View periodically
REFRESH MATERIALIZED VIEW mv_daily_sales_summary;

3. Common Table Expressions (CTEs)

A CTE is a temporary named result set defined within the execution scope of a single SELECT, INSERT, UPDATE, or DELETE query using the WITH clause. 

WITH RegionalSales AS (
    SELECT region, SUM(amount) as total_sales
    FROM orders
    GROUP BY region
),
TopRegions AS (
    SELECT region
    FROM RegionalSales
    WHERE total_sales > 100000
)
SELECT r.region, o.order_id, o.amount
FROM orders o
JOIN TopRegions r ON o.region = r.region;

4. Recursive CTEs (Hierarchical Data)

Recursive CTEs allow querying tree structures like organizational charts, category hierarchies, and bill-of-materials. 

-- Recursive CTE to generate an Employee Hierarchy
WITH RECURSIVE OrgChart AS (
    -- Anchor member: Top Manager (no manager_id)
    SELECT id, name, manager_id, 1 as level
    FROM employees
    WHERE manager_id IS NULL

    UNION ALL

    -- Recursive member: Employees reporting to manager
    SELECT e.id, e.name, e.manager_id, o.level + 1
    FROM employees e
    JOIN OrgChart o ON e.manager_id = o.id
)
SELECT * FROM OrgChart ORDER BY level, name;
