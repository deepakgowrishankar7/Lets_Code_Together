Introduction to SQL

SQL (Structured Query Language) is the standard language for working with relational databases. It allows you to create, read, update, and delete data and to define the structure and rules of the database.

Relational Database Basics

Relational databases store data in tables made of rows and columns. Tables are linked using keys (primary keys and foreign keys) so you can model relationships between entities.

Core SQL Categories

  • DDL (Data Definition Language): CREATE, ALTER, DROP — define schema.
  • DML (Data Manipulation Language): SELECT, INSERT, UPDATE, DELETE — read and modify data.
  • DCL (Data Control Language): GRANT, REVOKE — manage permissions.
  • TCL (Transaction Control Language): COMMIT, ROLLBACK — manage transactions.

Example Table

CREATE TABLE employees (
  id INT PRIMARY KEY,
  first_name VARCHAR(100),
  last_name VARCHAR(100),
  department VARCHAR(50),
  salary DECIMAL(10,2)
);

Simple SELECT Query

SELECT first_name, last_name
FROM employees
WHERE department = 'Sales';

How SQL Works (High Level)

  1. You write a SQL statement describing the data you want.
  2. The database parses and optimizes the query.
  3. The query runs and returns rows (or changes data for write queries).

Installing a Database (Quick Guide)

There are many SQL engines. Below are quick installation and verification steps for three common choices: MySQL, PostgreSQL, and SQLite. Choose the one you prefer — examples in this course work across them with minor syntax differences.

MySQL (Windows / macOS / Linux)

  1. Download MySQL Community Server from dev.mysql.com.
  2. Run the installer or follow your OS package manager instructions.
  3. Start the MySQL service (varies by OS).
  4. Verify installation in a terminal: mysql --version.
  5. Connect to server: mysql -u root -p and enter the root password.

PostgreSQL (Windows / macOS / Linux)

  1. Download the installer from postgresql.org or use your package manager.
  2. Install and start the PostgreSQL service.
  3. Verify: psql --version.
  4. Connect: psql -U postgres and enter your password.

SQLite (lightweight, no server)

  1. SQLite is often preinstalled. Verify with: sqlite3 --version.
  2. Create a database file and open it: sqlite3 mydb.sqlite.
  3. SQLite is ideal for quick local experiments and for embedding in apps.

Basic Quickstart (Create DB, Table, Insert, Select)

The SQL shown below works in MySQL and PostgreSQL (SQLite may have minor syntax differences):

-- create database (server engines)
CREATE DATABASE school;
USE school; -- MySQL. For Postgres: \c school

-- create table
CREATE TABLE students (
  id SERIAL PRIMARY KEY,
  name VARCHAR(100) NOT NULL,
  grade INT
);

-- insert rows
INSERT INTO students (name, grade) VALUES ('Asha', 10), ('Sam', 9);

-- read rows
SELECT * FROM students;

Connecting from Python (example using SQLite)

import sqlite3
conn = sqlite3.connect('school.sqlite')
cur = conn.cursor()
cur.execute('CREATE TABLE IF NOT EXISTS students (id INTEGER PRIMARY KEY, name TEXT, grade INTEGER)')
cur.execute("INSERT INTO students (name, grade) VALUES ('Asha', 10)")
conn.commit()
for row in cur.execute('SELECT * FROM students'):
    print(row)
conn.close()
