SQL Aggregate Functions

Aggregate functions summarize many rows into a single result. They are essential for reports and analytics.

COUNT

Counts rows or non-null values.

SELECT COUNT(*) AS total_orders
FROM orders;

SUM / AVG

Use SUM for totals and AVG for averages.

SELECT SUM(amount) AS total_sales,
       AVG(amount) AS average_order
FROM orders;

MIN / MAX

SELECT MIN(price) AS lowest_price,
       MAX(price) AS highest_price
FROM products;

GROUP BY

Group rows together before aggregating.

SELECT department,
       COUNT(*) AS employee_count,
       AVG(salary) AS average_salary
FROM employees
GROUP BY department;

HAVING

Filter groups after aggregation. This is like WHERE, but works on grouped results.

SELECT department,
       COUNT(*) AS employee_count
FROM employees
GROUP BY department
HAVING COUNT(*) > 5;

DISTINCT with Aggregates

SELECT COUNT(DISTINCT department) AS unique_departments
FROM employees;

Ordering Aggregated Results

SELECT department,
       SUM(sales) AS total_sales
FROM sales
GROUP BY department
ORDER BY total_sales DESC;
