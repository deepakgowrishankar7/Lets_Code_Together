SQL Joins

Joins combine data from multiple tables using common columns. This is how relational databases let you answer real questions.

Example Tables

customers
+----+----------+
| id | name     |
+----+----------+
|  1 | Asha     |
|  2 | Sam      |
+----+----------+

orders
+----+-------------+-------------+
| id | customer_id | order_date  |
+----+-------------+-------------+
| 10 |           1 | 2026-06-01  |
| 11 |           2 | 2026-06-02  |
+----+-------------+-------------+

INNER JOIN

Returns rows that match in both tables.

SELECT c.name, o.order_date
FROM customers c
INNER JOIN orders o ON c.id = o.customer_id;

LEFT JOIN

Returns all rows from the left table and matching rows from the right table.

SELECT c.name, o.order_date
FROM customers c
LEFT JOIN orders o ON c.id = o.customer_id;

RIGHT JOIN

Returns all rows from the right table and matching rows from the left table.

SELECT c.name, o.order_date
FROM customers c
RIGHT JOIN orders o ON c.id = o.customer_id;

FULL OUTER JOIN

Returns rows when there is a match in either table.

SELECT c.name, o.order_date
FROM customers c
FULL OUTER JOIN orders o ON c.id = o.customer_id;

CROSS JOIN

Returns every combination of rows from both tables.

SELECT c.name, o.order_date
FROM customers c
CROSS JOIN orders o;

Self Join

Join a table to itself. Useful for hierarchical or related data in the same table.

SELECT e1.name AS employee,
       e2.name AS manager
FROM employees e1
LEFT JOIN employees e2 ON e1.manager_id = e2.id;

Using Aliases

Aliases make joins easier to read and avoid ambiguity.
