SQL Window Functions & Analytical Queries

Window Functions perform calculations across a set of table rows related to the current row without collapsing rows into a single summary output (unlike GROUP BY).

1. Syntax of Window Functions

FUNCTION_NAME() OVER (
    [PARTITION BY partition_column]
    [ORDER BY sort_column]
    [ROWS|RANGE frame_specification]
)

2. Ranking Functions (`ROW_NUMBER`, `RANK`, `DENSE_RANK`)

Consider an employees table with departments and salaries:

SELECT 
    name, 
    department, 
    salary,
    ROW_NUMBER() OVER (PARTITION BY department ORDER BY salary DESC) as row_num,
    RANK()       OVER (PARTITION BY department ORDER BY salary DESC) as rank_num,
    DENSE_RANK() OVER (PARTITION BY department ORDER BY salary DESC) as dense_rank_num
FROM employees;
Key Differences:
  • ROW_NUMBER(): Assigns unique sequential integers (1, 2, 3, 4).
  • RANK(): Assigns rank with gaps for ties (1, 2, 2, 4).
  • DENSE_RANK(): Assigns rank without gaps for ties (1, 2, 2, 3).

3. Value Functions (`LEAD`, `LAG`)

LAG() accesses data from a previous row, and LEAD() accesses data from a subsequent row without requiring self-joins. 

-- Calculate month-over-month sales growth
SELECT 
    month,
    sales,
    LAG(sales, 1) OVER (ORDER BY month) as prev_month_sales,
    sales - LAG(sales, 1) OVER (ORDER BY month) as monthly_growth
FROM monthly_sales;
Expected Output: 
+-------+-------+------------------+----------------+
| month | sales | prev_month_sales | monthly_growth |
+-------+-------+------------------+----------------+
| Jan   | 10000 | NULL             | NULL           |
| Feb   | 12500 | 10000            | +2500          |
| Mar   | 15000 | 12500            | +2500          |
+-------+-------+------------------+----------------+

4. Running Total & Moving Average

You can accumulate sums or averages dynamically using window frames:

-- Running total of sales per customer
SELECT 
    order_id,
    customer_id,
    amount,
    SUM(amount) OVER (
        PARTITION BY customer_id 
        ORDER BY order_date
        ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW
    ) as cumulative_spent
FROM orders;
