SQL Basic Queries

Basic queries let you ask the database for exactly the data you need. Start simple, then add filters, sorting, and limits.

SELECT Columns

Use SELECT to choose columns, and FROM to choose the table.

SELECT first_name, last_name
FROM employees;

Select All Columns

SELECT *
FROM employees;

Use Aliases

Aliases make results easier to read.

SELECT first_name AS first,
       last_name AS last,
       salary AS pay
FROM employees;

Filter Rows with WHERE

SELECT *
FROM employees
WHERE department = 'Sales';

Common WHERE Conditions

  • =, <>, <, >
  • BETWEEN 10000 AND 50000
  • IN ('Sales', 'IT')
  • LIKE 'A%'
  • IS NULL or IS NOT NULL
SELECT name, salary
FROM employees
WHERE salary >= 50000
  AND department IN ('IT', 'Sales');

Sort Results

SELECT name, salary
FROM employees
ORDER BY salary DESC;

Limit Rows

SELECT *
FROM employees
ORDER BY hired_date DESC
LIMIT 5;

Skip Rows with OFFSET

SELECT *
FROM employees
ORDER BY id
LIMIT 10 OFFSET 10;

Remove Duplicates

SELECT DISTINCT department
FROM employees;

Understand Query Order

The database processes FROM first, then WHERE, then SELECT. That means filtering happens before selecting the final columns.
