Describe JVM Stack vs Heap memory and how GC works.

Answer: Stack: thread-private, stores frames (locals, operands). Heap: shared, stores objects. GC: marks live objects from GC roots (stack refs, static fields), sweeps unreachable objects. What is type erasure in Java Generics?

Answer: Generic type information is erased at compile time and replaced with Object (or the upper bound). This maintains backward compatibility with pre-generics code.
