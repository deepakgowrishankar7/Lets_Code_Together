Java I/O, NIO.2 & Serialization

Java provides rich APIs for reading and writing data to files, memory, and network sockets. Java NIO.2 (`java.nio.file`) introduced non-blocking I/O, channels, buffers, and modern file operations.

1. Traditional I/O vs Java NIO

  • Stream-Oriented I/O (`java.io`): Reads data byte-by-byte or character-by-character sequentially. Blocking operation.
  • Buffer-Oriented NIO (`java.nio`): Reads data into buffers through channels. Supports non-blocking operations.

2. Java NIO.2: `Path` and `Files` APIs

Java 7+ introduced Path and Files utility classes for intuitive file operations.

import java.io.IOException;
import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.Paths;
import java.util.List;

public class NioFileExample {
    public static void main(String[] args) {
        Path path = Paths.get("example.txt");

        try {
            // Write string to file
            Files.writeString(path, "Hello Java NIO.2 World!\nSecond Line");

            // Read all lines
            List lines = Files.readAllLines(path);
            lines.forEach(System.out.println);

            // Check existence
            System.out.println("File exists? " + Files.exists(path));
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}

3. Object Serialization & Deserialization

Serialization is the mechanism of converting an object's state into a byte stream. Deserialization recreates the object from the byte stream. 

import java.io.*;

// Must implement Serializable marker interface
class User implements Serializable {
    private static final long serialVersionUID = 1L;

    private String username;
    private transient String password; // 'transient' prevents field from being serialized!

    public User(String username, String password) {
        this.username = username;
        this.password = password;
    }

    @Override
    public String toString() {
        return "User{username='" + username + "', password='" + password + "'}";
    }
}

public class SerializationDemo {
    public static void main(String[] args) {
        User user = new User("admin", "SecretPass123!");

        // Serialize Object
        try (ObjectOutputStream out = new ObjectOutputStream(new FileOutputStream("user.ser"))) {
            out.writeObject(user);
            System.out.println("Object serialized successfully.");
        } catch (IOException e) {
            e.printStackTrace();
        }

        // Deserialize Object
        try (ObjectInputStream in = new ObjectInputStream(new FileInputStream("user.ser"))) {
            User deserializedUser = (User) in.readObject();
            System.out.println("Deserialized: " + deserializedUser);
            // Password will be null because it was marked transient!
        } catch (IOException | ClassNotFoundException e) {
            e.printStackTrace();
        }
    }
}

4. Channels and Buffers Overview

In Java NIO, data is read from a Channel into a Buffer, or written from a Buffer into a Channel.

  • Buffer: Memory block (`ByteBuffer`, `CharBuffer`, `IntBuffer`). Has `capacity`, `position`, `limit`.
  • Channel: Connection to an entity capable of I/O operations (`FileChannel`, `SocketChannel`).
