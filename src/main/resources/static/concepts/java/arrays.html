Java Arrays

Beginner Read Time: 10 mins

1. The Real-World Analogy: A Row of Lockers

Imagine a school corridor with a long row of 10 school lockers set side-by-side. Each locker is the exact same size, and they are labeled with numbers starting from Locker 0 to Locker 9.

An Array is that row of lockers. You specify how many lockers you need at the beginning, they are placed adjacent to each other in memory (contiguous), and you can put items inside or retrieve items by specifying the index number.

2. Key Array Properties

  • Fixed Size: Once created, you cannot change the size of the array. If you need more space, you must create a new array and copy the elements.
  • Contiguous Memory: Elements are stored in continuous memory slots in the Heap. This makes accessing elements extremely fast (constant time O(1)) if you know the index.
  • Zero-Indexed: In Java, the first element of an array is always at index 0, and the last is at length - 1.
  • Homogeneous Data: All elements must be of the same data type.

⚠️ Warning: ArrayIndexOutOfBoundsException!

If you try to read or write to an index that doesn't exist (e.g. accessing index 5 in a 5-element array whose valid indices are 0 to 4), Java will throw an ArrayIndexOutOfBoundsException and crash your application.

3. Single vs. Multi-Dimensional Arrays

Arrays can be nested to represent grids, spreadsheets, or matrices.

a. 1D Arrays (A Single Row)

int[] grades = new int[5]; // Declares an array of 5 integers, initialized to default (0)
grades[0] = 95;
grades[1] = 88;

b. 2D Arrays (A Grid / Matrix)

A 2D array is simply an "array of arrays" representing rows and columns:

int[][] matrix = {
    {1, 2, 3}, // Row 0
    {4, 5, 6}  // Row 1
};
int val = matrix[1][2]; // Accesses Row 1, Column 2 (Value: 6)

💻 Example Code & Line-by-Line Breakdown

public class ArrayDemo {
    public static void main(String[] args) {
        String[] fruits = {"Apple", "Banana", "Cherry"};
        
        // Loop through array using length property
        for (int i = 0; i < fruits.length; i++) {
            System.out.println("Fruit at index " + i + ": " + fruits[i]);
        }
    }
}

Line-by-Line Breakdown:

  • String[] fruits = {"Apple", "Banana", "Cherry"};: Shorthand initialization syntax. Creates a String array of size 3 in the Heap and fills it.
  • i < fruits.length: Uses the read-only length property of arrays to determine when to stop looping. Crucial to prevent bounds crashing.
  • fruits[i]: Retrieves the string item located at index i.

Q1: Why are arrays zero-indexed in Java?

A: The index number represents the memory offset from the starting address of the array. Since the first element is located exactly at the starting address, its offset is 0. The address of index i is calculated as: Start_Address + (i * element_size).

Q2: What is the difference between an Array and an ArrayList?

A: An array is fixed-size and can hold both primitives and objects. An ArrayList is a dynamic resizeable Collection wrapper that holds only objects, resizing itself automatically by allocating a new array and copying items when it gets full.
