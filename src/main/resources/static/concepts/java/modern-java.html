Modern Java: Lambdas & Streams

Intermediate Read Time: 12 mins

1. The Real-World Analogy: Water Filtration Pipeline

Imagine a raw water processing plant. Water flows through a pipe (Stream):

  1. First, it passes through a mesh grid to filter out leaves (Intermediate: filter).
  2. Next, it flows through a dispenser that adds mineral vitamins, transforming it into drinking water (Intermediate: map).
  3. Finally, the processed water is collected into storage bottles ready for distribution (Terminal: collect).

In Modern Java, the Stream API works exactly like this pipe. It lets you process collections of data declaratively through a pipeline of operations without using messy loops.

2. Functional Programming & Lambda Expressions

Introduced in Java 8, Lambda Expressions provide a clear, concise inline syntax to represent anonymous functional interfaces (interfaces containing exactly one abstract method). They allow you to treat code as arguments.

// Traditional anonymous class
Runnable r1 = new Runnable() {
    public void run() { System.out.println("Hello"); }
};

// Modern Lambda expression shorthand
Runnable r2 = () -> System.out.println("Hello");

⚠️ Warning: Streams Can Only Be Consumed Once!

A Java Stream is like a physical conveyor belt: once items pass through and are collected, the conveyor is empty. If you try to call multiple terminal operations on the same Stream variable (e.g. counting and then collecting), Java throws an IllegalStateException.

3. Stream Operations: Intermediate vs. Terminal

A Stream pipeline consists of a data source (like a List), followed by zero or more intermediate operations, and exactly one terminal operation:

  • Intermediate Operations (Lazy): Transform the stream into another stream (e.g., filter(Predicate), map(Function), sorted()). They do not execute until a terminal operation is invoked.
  • Terminal Operations (Eager): Execute the pipeline and return a non-stream result (e.g., collect(), forEach(), reduce(), count()). Once called, the Stream is closed.

💻 Example Code: Stream Processing

import java.util.*;
import java.util.stream.*;

public class StreamDemo {
    public static void main(String[] args) {
        List<String> names = Arrays.asList("Alex", "Bob", "Alice", "David");

        // Filter names starting with 'A', convert to uppercase, and collect
        List<String> result = names.stream()
            .filter(name -> name.startsWith("A")) // Intermediate (Lazy)
            .map(String::toUpperCase)              // Intermediate (Lazy)
            .collect(Collectors.toList());        // Terminal (Eager)

        System.out.println(result); // Outputs: [ALEX, ALICE]
    }
}

Line-by-Line Breakdown:

  • names.stream(): Opens a pipeline wrapper over the standard collection list.
  • filter(name -> ...): Discards strings that do not start with 'A'. The argument is a lambda expression representing a Predicate.
  • map(String::toUpperCase): Transforms each string using a **Method Reference** (shorthand for s -> s.toUpperCase()).
  • collect(Collectors.toList()): Closes the stream and saves the resulting items into a new list.

💬 Topic Interview Prep Q&A

Microsoft Netflix

Q1: Explain intermediate vs. terminal stream operations and why streams are lazy.

A: Intermediate operations return a new Stream and are lazy because they do not execute immediately; they only register the filter/map callback actions. Terminal operations are eager; they trigger the actual traversal and processing of data, executing intermediate filters in a single efficient pass.

Amazon

Q2: What are Functional Interfaces in Java? Give examples.

A: A functional interface is an interface containing exactly one abstract method (marked optionally with @FunctionalInterface). Standard examples in java.util.function include: Predicate<T> (returns boolean), Function<T, R> (maps inputs), Consumer<T> (consumes inputs, returns void), and Supplier<T> (returns values).
