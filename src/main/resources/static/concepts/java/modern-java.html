Modern Java (Java 8 to Java 21+)

Java has evolved rapidly since Java 8. Modern Java emphasizes functional programming techniques, immutability, concise syntax, high performance, and pattern matching.

1. Lambda Expressions & Functional Interfaces

A lambda expression is an anonymous function that can be passed around like a value. A Functional Interface contains exactly one abstract method. 

import java.util.function.*;

public class LambdaExample {
    public static void main(String[] args) {
        // Predicate: takes an input and returns boolean
        Predicate isEven = n -> n % 2 == 0;
        
        // Function: transforms T into R
        Function stringLength = str -> str.length();

        // Consumer: takes input and returns nothing
        Consumer printer = msg -> System.out.println("LOG: " + msg);

        System.out.println("Is 4 even? " + isEven.test(4));
        System.out.println("Length of 'Java': " + stringLength.apply("Java"));
        printer.accept("Lambda Functional Demo");
    }
}

2. Java Stream API

The Stream API is used to process sequences of elements imperatively and declaratively. It supports filtering, mapping, sorting, and reduction. 

import java.util.Arrays;
import java.util.List;
import java.util.stream.Collectors;

public class StreamExample {
    public static void main(String[] args) {
        List names = Arrays.asList("Alice", "Bob", "Charlie", "David", "Amanda");

        // Filter names starting with 'A', uppercase them, and collect into a list
        List result = names.stream()
                .filter(name -> name.startsWith("A"))
                .map(String::toUpperCase)
                .sorted()
                .collect(Collectors.toList());

        System.out.println(result); // [ALICE, AMANDA]
    }
}

3. `Optional` to Avoid `NullPointerException`

Optional is a container object used to contain non-null values and explicitly handle the absence of a value. 

import java.util.Optional;

public class OptionalExample {
    public static void main(String[] args) {
        Optional name = Optional.ofNullable(getName());

        String defaultName = name.orElse("Guest User");
        System.out.println("Hello, " + defaultName);
    }

    static String getName() {
        return null; // Could return null
    }
}

4. Java 14+ Records (Immutable Data Carriers)

Records provide a compact syntax to declare classes that are transparent holders for immutable data, eliminating boilerplate getters, `equals()`, `hashCode()`, and `toString()`. 

// Record declaration (1 line!)
public record Student(int id, String name, double gpa) {}

public class RecordDemo {
    public static void main(String[] args) {
        Student student = new Student(101, "Alex", 3.9);

        System.out.println(student.name()); // Accessor method name()
        System.out.println(student);        // Student[id=101, name=Alex, gpa=3.9]
    }
}

5. Pattern Matching & Switch Expressions (Java 17+)

Pattern matching reduces boilerplate when checking types and casting objects. Switch expressions return values and reduce fallthrough bugs. 

public class PatternMatchingDemo {
    public static void main(String[] args) {
        Object obj = "Hello Java 21";

        // Pattern matching for instanceof
        if (obj instanceof String s) {
            System.out.println("String length: " + s.length());
        }

        // Switch expression
        String day = "MONDAY";
        int type = switch (day) {
            case "MONDAY", "FRIDAY" -> 1;
            case "TUESDAY" -> 2;
            default -> 0;
        };
        System.out.println("Day code: " + type);
    }
}
