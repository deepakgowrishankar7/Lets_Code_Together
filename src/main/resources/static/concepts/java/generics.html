Java Generics & Type Safety

Generics were introduced in Java 5 to enable types (classes and interfaces) to be parameters when defining classes, interfaces, and methods. Generics enforce type safety at compile time and eliminate explicit casting.

1. Why Generics?

Before Generics, collections stored raw Objects, requiring manual casting and risking runtime ClassCastExceptions:

// WITHOUT Generics (Unsafe)
List list = new ArrayList();
list.add("Hello");
String s = (String) list.get(0); // Explicit cast required

// WITH Generics (Type-Safe)
List safeList = new ArrayList<>();
safeList.add("Hello");
String str = safeList.get(0); // Compile-time safety, no cast needed!

2. Generic Classes & Interfaces

You can create custom classes that work with any object type:

public class Box {
    private T item;

    public void set(T item) {
        this.item = item;
    }

    public T get() {
        return item;
    }

    public static void main(String[] args) {
        Box intBox = new Box<>();
        intBox.set(100);
        System.out.println("Box integer: " + intBox.get());

        Box strBox = new Box<>();
        strBox.set("Java Generics");
        System.out.println("Box string: " + strBox.get());
    }
}

3. Bounded Type Parameters

You can restrict the types that can be passed to a type parameter using extends. 

// Restrict T to Number or its subclasses (Integer, Double, etc.)
public class MathUtils {
    public static  double doubleValue(T number) {
        return number.doubleValue();
    }

    public static void main(String[] args) {
        System.out.println(doubleValue(42));    // Works with Integer
        System.out.println(doubleValue(3.1415)); // Works with Double
        // doubleValue("String"); // COMPILE ERROR! String is not a Number.
    }
}

4. Wildcards in Generics (`?`, `? extends T`, `? super T`)

Wildcards (`?`) represent unknown types in generic parameters:

  • Unbounded Wildcard (``): Accepts any type.
  • Upper Bounded Wildcard (``): Accepts T or any subclass of T (Read-only / Producer).
  • Lower Bounded Wildcard (``): Accepts T or any superclass of T (Consumer).
import java.util.List;

public class WildcardDemo {
    // Upper Bounded Wildcard: accepts List of Number or subclasses (Integer, Double)
    public static double sumOfList(List list) {
        double sum = 0.0;
        for (Number n : list) {
            sum += n.doubleValue();
        }
        return sum;
    }

    public static void main(String[] args) {
        List integers = List.of(10, 20, 30);
        List doubles = List.of(1.5, 2.5, 3.5);

        System.out.println("Integer Sum: " + sumOfList(integers)); // 60.0
        System.out.println("Double Sum: " + sumOfList(doubles));   // 7.5
    }
}

5. Type Erasure

Java Generics are implemented via Type Erasure. The JVM compiler removes all generic type information at compile time and inserts necessary casts, ensuring backward compatibility with older Java versions.
