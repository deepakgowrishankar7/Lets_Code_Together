Classes & Objects

Beginner Read Time: 9 mins

1. The Real-World Analogy: Blueprint vs. House

Imagine an architect draws a detailed paper blueprint for a suburban villa. The blueprint is not a real house; you cannot sleep in it, cook in it, or stay warm in it. However, a builder can look at that blueprint and construct 10 physical houses in a neighborhood.

In Java, a Class is that paper blueprint (an abstract definition), and an Object is the actual physical house built on the ground (residing in Heap memory).

2. Anatomy of a Class

A class wraps two main features to describe real-world entities:

  • State (Fields / Attributes): Variables that store data representing the object's properties (e.g., color, size).
  • Behavior (Methods): Functions that define what actions the object can perform (e.g., run(), stop()).

⚠️ Warning: The Dreaded NullPointerException!

When you declare an object reference variable like Car myCar;, it starts as null. If you try to invoke a method on it (e.g., myCar.drive()) before assigning an actual object to it using the new keyword, Java throws a NullPointerException and stops execution.

3. Instantiation & Heap Allocation

Objects are instantiated using the new keyword, which tells the JVM to allocate memory for the object's instance fields on the Heap.

// 'myCar' is a reference variable on the Stack pointing to a Car object on the Heap
Car myCar = new Car();

💻 Example Code & Line-by-Line Breakdown

public class Dog {
    // State / Attributes
    String breed;
    int age;

    // Behavior / Method
    public void bark() {
        System.out.println("Woof! Woof!");
    }

    public static void main(String[] args) {
        // Instantiating objects
        Dog puppy = new Dog();
        puppy.breed = "Beagle";
        puppy.age = 2;

        puppy.bark(); // Prints "Woof! Woof!"
    }
}

Line-by-Line Breakdown:

  • public class Dog: Defines the class blueprint name.
  • String breed; int age;: Fields representing the dog's state.
  • Dog puppy = new Dog();: Allocates memory for a Dog instance on the Heap. The variable puppy on the Stack holds the memory address reference of that object.
  • puppy.breed = "Beagle";: Accesses the instance fields of the Heap object using the dot (.) operator.

💬 Topic Interview Prep Q&A

Google Amazon

Q1: What is the difference between a Class and an Object?

A: A Class is a logical template or blueprint defining properties and behaviors. An Object is a physical instance of that class allocated in memory, which holds its own runtime values for those fields.

Apple

Q2: What is class loading in Java?

A: When a program runs, the JVM's ClassLoader reads class metadata from the .class byte-code file, loads it into the Method Area, and creates a java.lang.Class object representing it before any object of that class can be created.
