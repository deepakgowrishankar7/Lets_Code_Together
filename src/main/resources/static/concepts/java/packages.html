Packages & Access Modifiers

Beginner Read Time: 8 mins

1. The Real-World Analogy: Directory Folders

Imagine you have 1,000 documents on your computer. If you dump them all on your Desktop, you will have a chaotic mess. Instead, you create folders: "Taxes", "Photos", and "Resume".

In Java, Packages are those directories, letting you group related classes together so they are easy to locate, maintain, and secure.

2. Importing & Namespace Management

Every class in Java resides inside a package. The package name corresponds directly to the directory path of the class file. To use a class located in another package, you must **import** it:

package com.company.app; // Declares the package

import java.util.ArrayList; // Imports a specific class
import java.util.Date;      // Imports another class

⚠️ Warning: Class Name Conflicts!

If you import two packages containing classes with the exact same name (e.g., java.util.Date and java.sql.Date), Java won't know which one to instantiate. You must use the fully qualified class name in your code, like: java.util.Date myDate = new java.util.Date();.

3. Access Modifiers: The Security Gates

Access modifiers control who is allowed to view, modify, or instantiate classes, methods, and variables:

Modifier Same Class Same Package Subclass (Different Package) World (Anywhere)
private ✅ Yes ❌ No ❌ No ❌ No
default (No keyword) ✅ Yes ✅ Yes ❌ No ❌ No
protected ✅ Yes ✅ Yes ✅ Yes (via inheritance) ❌ No
public ✅ Yes ✅ Yes ✅ Yes ✅ Yes

💻 Example Code & Line-by-Line Breakdown

package com.academy.geometry;

public class Shape {
    public String shapeName = "Circle"; // Accessible from anywhere
    protected int area = 50;            // Subclasses & package-only
    int perimeter = 30;                 // Package-only (default)
    private String secretKey = "12345"; // Class-only
}

Line-by-Line Breakdown:

  • package com.academy.geometry;: Tells Java that this class file resides physically inside the folder path com/academy/geometry/.
  • public String shapeName;: Any class in any project package can read this variable.
  • protected int area;: If a class Square in package com.academy.other inherits from Shape, it can access area, but other external classes cannot.
  • private String secretKey;: Absolutely no other class, not even a subclass, can see or access this field.

💬 Topic Interview Prep Q&A

Oracle

Q1: Explain the difference between protected and default (package-private) access modifiers.

A: A default member is accessible ONLY to classes located inside the same package. A protected member is accessible to classes in the same package, but is also visible to subclasses in different packages through inheritance (using extends).

Amazon

Q2: What is a package-info.java file?

A: It is a Java file placed in a package folder to document package-level features, declare package-level annotations, and provide package-level Javadocs.
