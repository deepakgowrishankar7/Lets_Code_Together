Java Multithreading & Concurrency

Multithreading in Java is a process of executing multiple threads simultaneously to maximize CPU utilization. A thread is a lightweight sub-process, the smallest unit of processing.

Core Concepts: Thread vs Process

  • Process: An isolated program in execution with its own memory space.
  • Thread: A subset of a process that shares memory and resources with other threads of the same process.

1. Creating Threads in Java

There are two primary ways to create a thread in Java:

  1. By extending the Thread class
  2. By implementing the Runnable interface (Recommended)

Option A: Implementing Runnable

class MyRunnable implements Runnable {
    @Override
    public void run() {
        System.out.println("Thread running: " + Thread.currentThread().getName());
    }
}

public class Main {
    public static void main(String[] args) {
        Thread thread1 = new Thread(new MyRunnable(), "Worker-1");
        Thread thread2 = new Thread(new MyRunnable(), "Worker-2");
        
        thread1.start();
        thread2.start();
    }
}
Output: 
Thread running: Worker-1
Thread running: Worker-2

2. Thread Life Cycle & States

A Java thread can exist in one of the following states (defined in Thread.State):

  • NEW: Created but not yet started.
  • RUNNABLE: Executing in the JVM or ready to execute.
  • BLOCKED: Waiting for a monitor lock to enter a synchronized block/method.
  • WAITING: Waiting indefinitely for another thread to perform a specific action (`wait()`, `join()`).
  • TIMED_WAITING: Waiting for a specified time (`sleep(ms)`, `wait(ms)`).
  • TERMINATED: Finished execution.

3. Synchronization & Thread Safety

When multiple threads access shared mutable data, race conditions can occur. Use the synchronized keyword or explicit locks to guarantee mutual exclusion. 

class Counter {
    private int count = 0;

    // Synchronized method prevents race condition
    public synchronized void increment() {
        count++;
    }

    public int getCount() {
        return count;
    }
}

public class SyncExample {
    public static void main(String[] args) throws InterruptedException {
        Counter counter = new Counter();

        Thread t1 = new Thread(() -> {
            for (int i = 0; i < 1000; i++) counter.increment();
        });

        Thread t2 = new Thread(() -> {
            for (int i = 0; i < 1000; i++) counter.increment();
        });

        t1.start();
        t2.start();
        t1.join();
        t2.join();

        System.out.println("Final Count: " + counter.getCount()); // Always 2000
    }
}

4. Inter-Thread Communication (`wait`, `notify`)

Threads can communicate using wait(), notify(), and notifyAll() methods inside a synchronized context. 

class SharedResource {
    private boolean available = false;

    public synchronized void produce() throws InterruptedException {
        while (available) {
            wait(); // Wait until consumed
        }
        System.out.println("Produced item.");
        available = true;
        notify(); // Notify consumer thread
    }

    public synchronized void consume() throws InterruptedException {
        while (!available) {
            wait(); // Wait until produced
        }
        System.out.println("Consumed item.");
        available = false;
        notify(); // Notify producer thread
    }
}

5. Advanced Concurrency: ExecutorService & Concurrent Collections

Instead of managing threads manually, Java 5 introduced java.util.concurrent with thread pools, ExecutorService, Future, and high-performance concurrent collections like ConcurrentHashMap and CopyOnWriteArrayList. 

import java.util.concurrent.ExecutorService;
import java.util.concurrent.Executors;

public class ThreadPoolExample {
    public static void main(String[] args) {
        ExecutorService executor = Executors.newFixedThreadPool(3);

        for (int i = 1; i <= 5; i++) {
            final int taskId = i;
            executor.submit(() -> {
                System.out.println("Executing Task " + taskId + " on thread: " + Thread.currentThread().getName());
            });
        }

        executor.shutdown();
    }
}
